# Quiz em Java

Projeto desenvolvido em Java para criação de um Quiz com 15 questões.

## Tecnologias

- Java
- Console (Terminal)

## Estrutura

- `Questao.java`: classe responsável pelos dados e funcionalidades das questões.
- `Main.java`: responsável pela execução do Quiz e interação com o usuário.

## Objetivo

Desenvolver um Quiz sobre conceitos importantes da linguagem Java.
